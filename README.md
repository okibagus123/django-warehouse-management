# 📦 Django Warehouse Management System (WMS)

Sistem Manajemen Gudang (*Warehouse Management System*) berbasis web yang dikembangkan menggunakan **Python (Django Framework)**. Aplikasi ini dirancang untuk mempermudah pengelolaan inventaris, pencatatan data barang, pengelompokan kategori, serta manajemen profil pengguna secara terstruktur dan efisien.

---

## 🚀 Fitur Utama

* **Manajemen Inventaris Barang:** Mengelola data stok barang masuk dan keluar secara *real-time*.
* **Sistem Kategori & Klasifikasi:** Pengorganisasian produk berdasarkan kategori untuk memudahkan pencarian dan pemantauan stok gudang.
* **Manajemen Profil & Media:** Pengelolaan data akun dan direktori penyimpanan file/media pengguna (*media/profile*).
* **Autentikasi & Keamanan:** Sistem *login* berbasis sesi bawaan Django untuk melindungi data operasional gudang dari akses yang tidak berwenang.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django 
* **Frontend:** HTML5, CSS3, JavaScript (Template Engine bawaan Django)
* **Database:** SQLite (Default Django ORM) / Konfigurasi MySQL Opsional
* **Manajemen File:** Django Media Files Management
